LSJ: The JSL Mirror
=================================


LSJ is a tool for performing the compile-time reflection required for the ``Interface`` module of the [JSL](https://github.com/DrFraserGovil/JSL). 

Install
--------

This tool can be acquired in the following way:

```
git clone git@github.com:DrFraserGovil/LSJ
cd LSJ
make
```

Compiling this requires either a copy of the JSL library to be on your $PATH, or an internet connection sufficient for the ``FetchContent`` directive to clone a copy to the build directory.
  
Usage
----------

Basic usage:

```
./lsj target1.h target2.h ... 
```

When multiple files are passed to a single instance, they are assumed to be associated with the same project, and so errors and warnings will surface if aliases are shared between variables across files. 

The LSJ is bootstrapped, and uses an LSJ-written interface to provide runtime modification of its behaviour:

```

=================================== Commands ===================================

help            Activates the help display, then exits (equivalent to -h)       


================================= SettingsObj =================================

-config         (Inbuilt)           If a file is passed to this argument, it is 
                <string>            used to configure the remaining parameters, 
                                    at a lower priority than values set from the
                                    command line                                
                                    [Default: -none-]                           
-config-delim   (Inbuilt)           This value is used to determine the         
                <string>            delimiter used to separate key-value pairs  
                                    in config files.                            
                                    [Default: ' ']                              
-h, -help       (Inbuilt)           If true, shows the help screen, then quits  
                <bool>              [Default: false]                            
-q              Quiet               Quiet mode                                  
                <bool>              [Default: false]                            
-v, -verbose    Verbose             Verbose                                     
                <bool>              [Default: false]                            

=============================== Inbuilt Strings ===============================

-suffix   Suffix            The name given to all autogenerated files to        
          <string>          indicate that they were generated with this tool    
                            [Default: .autogen]                                 

=================================== ModesObj ===================================

-f, -fix   ActiveFix          If true, enables source code alteration to fix    
           <bool>             CRTP errors                                       
                              [Default: false]                                  

```
